### Featured Projects

- **[NYC 311 Complaint Prediction](https://github.com/cranda98/aws-nyc311-cranda98)** — Built an AWS-based ML model (Logistic Regression) to predict 311 call categories, achieving 48.4% accuracy (2x better than random) by identifying and removing a key data leakage issue (the 'agency' field) for realistic routing suggestions.

- **[MSU Curriculum Mapping Tool](https://github.com/cranda98/MSU_Curriculum_Maps)** — End-to-end pipeline for cleaning academic course data, parsing complex prerequisite logic (AND/OR), and constructing a dependency graph to visualize student pathways using `networkx` and `plotly`.

- **[Educational Log Analysis Scripts](https://github.com/cranda98/log-analysis-scripts)** — Collection of Python utilities for processing large educational log files (CSV/JSON), including scripts for date-range checking, splitting by time, extracting nested JSON fields, and de-identifying sensitive data.
